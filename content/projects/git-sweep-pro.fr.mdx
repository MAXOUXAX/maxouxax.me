## Contexte

Les branches git locales s'accumulent rapidement lorsqu'une équipe fusionne
et supprime régulièrement ses branches distantes. Git Sweep Pro est une
extension VS Code qui identifie et supprime en toute sécurité les branches
locales qui n'existent plus sur le dépôt distant.

## Ce que j'ai construit

L'extension affiche les branches obsolètes directement dans la vue
"Contrôle de code source" de VS Code et permet de les nettoyer en quelques
clics :

- Détecte les branches dont l'upstream a été supprimé
- Affiche une étape de confirmation avant toute action destructrice
- Fonctionne entièrement en local, sans télémétrie

```bash
git fetch --prune
```
