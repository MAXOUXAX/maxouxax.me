## Context

> TODO(owner): rewrite this section.

Local git branches pile up fast once a team merges and deletes remote
branches regularly. Git Sweep Pro is a VS Code extension that safely
identifies and prunes local branches that no longer exist on the remote.

## What I built

> TODO(owner): rewrite this section.

The extension surfaces stale branches directly inside the VS Code source
control view and lets you clean them up in a couple of clicks:

- Detects branches whose upstream has been deleted
- Shows a confirmation step before any destructive action
- Runs entirely locally, no telemetry

```bash
git fetch --prune
```
